# Stop MOTIS Server

Stop MOTIS Server

## Usage

``` r
motis_stop_server(server = NULL, id = NULL, port = NULL, include_all = FALSE)
```

## Arguments

- server:

  A motis_server object.

- id:

  The server ID.

- port:

  The server port.

- include_all:

  Logical. If TRUE, allows stopping servers from other R sessions.
